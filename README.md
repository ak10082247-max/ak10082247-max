### 🚀 What I Build

I design, ship, and operate production-grade security, consumable data, and monetization primitives for the autonomous AI agent economy:

- 🛡️ **Sub-Millisecond Guardrails & Token Security:** Deterministic Layer-1 prompt injection firewalls and pre-swap DEX honeypot simulators running before LLM inference or on-chain execution.
- ⚡ **Consumable Agent Data Rails:** Real-time B2B intent signals, prompt-injection sanitized markdown web extractors, and live Shopify price/stock monitors built for autonomous agents, n8n, Make.com, and Clay.
- 💳 **Dual-Chain Machine-to-Machine Commerce:** Pay-per-call APIs monetized via **x402 V2** on **Base Mainnet (`eip155:8453`)** (EIP-712 gasless `TransferWithAuthorization`) and **Solana Mainnet** (SPL `TransferChecked` opcode 12 via PayAI gas sponsorship).
- 🤖 **Agent Framework Integrations:** Production plugins and Action Providers for **Model Context Protocol (MCP)**, **ElizaOS**, and **Coinbase AgentKit** runtimes.
